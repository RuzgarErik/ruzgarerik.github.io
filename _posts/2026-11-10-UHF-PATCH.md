## 1. Introduction

This report documents the design of a rectangular microstrip patch antenna for the 865–868 MHz European UHF RFID band. The design followed three steps:

1. **Analytical** — calculate all dimensions from closed-form formulas, run initial simulation
2. **Inset depth correction** — fix the feed inset depth (`cut_l`) using the method from an Altium article on inset-fed patch antennas, re-simulate
3. **HFSS optimisation** — use the HFSS built-in Quasi-Newton optimizer to tune the patch length (`pat_l`) and centre the resonance on 866.5 MHz

Target: S₁₁ < −10 dB across the full 865–868 MHz band with a broadside radiation pattern.

## 3. Step 1 — Analytical Design and Initial Simulation

### 3.1 Calculated Dimensions

All dimensions were derived from standard microstrip patch formulas.

**Patch width:**

$$W = \frac{c}{2f_0}\sqrt{\frac{2}{\varepsilon_r + 1}} = 105.35 \text{ mm}$$

**Effective permittivity:**

$$\varepsilon_{\text{eff}} = \frac{\varepsilon_r+1}{2} + \frac{\varepsilon_r-1}{2}\left(1+\frac{12h}{W}\right)^{-0.5} = 4.264$$

**Physical patch length** (accounting for fringing at both radiating edges):

$$L = \frac{c}{2f_0\sqrt{\varepsilon_{\text{eff}}}} - 2\Delta L = 82.35 \text{ mm}$$

**50 Ω feed line width:**

$$W_{\text{feed}} = 2.95 \text{ mm} \approx 3 \text{ mm}$$

**Inset feed depth** from the cosine-squared current distribution approximation, using the estimated patch edge resistance R_edge ≈ 323 Ω:

$$y_0 = \frac{L}{\pi}\arccos\!\sqrt{\frac{Z_0}{R_{\text{edge}}}} = 30.57 \text{ mm}$$

Notch width: `cut_w` = 3 × `tl_w` = 9 mm.

| Variable | Value |
|---|---|
| pat_w | 105.35 mm |
| pat_l | 82.35 mm |
| tl_w | 3 mm |
| cut_l | 30.57 mm |
| cut_w | 9 mm |

## 4. Step 2 — Inset Depth Correction

The analytically calculated inset depth (`cut_l` = 30.57 mm) was replaced with a corrected value determined using the Altium article on inset-fed patch antenna design. This method gives a more accurate feed point that accounts for the actual current distribution and notch geometry.

**Revised value: `cut_l` = 20.59 mm** (down from 30.57 mm). All other parameters unchanged.

### 4.1 Simulation Results After Inset Correction

![S11 after inset depth correction]({{ '/assets/patch/step2_altium/s11.png' | relative_url }})

*Figure 7. S₁₁ after correcting the inset depth. Minimum: −13.49 dB at 863.5 MHz. Within the 865–868 MHz band: −12.77 dB at 865 MHz, −11.70 dB at 866.5 MHz, −10.37 dB at 868 MHz.*

The match improved dramatically — from −4 dB to below −10 dB across the whole band. The resonance is still slightly off-centre (minimum at 863.5 MHz rather than 866.5 MHz) but the band is covered. The next step tunes the patch length to centre it properly.

![Smith chart after inset correction]({{ '/assets/patch/step2_altium/smith.png' | relative_url }})

*Figure 8. Smith chart after inset correction. The locus now passes near the chart centre, confirming good 50 Ω match across the band.*

![2D E-plane polar pattern after inset correction]({{ '/assets/patch/step2_altium/polar.png' | relative_url }})

*Figure 9. Radiation pattern after inset correction. Boresight gain: 0.927 dBi. Pattern shape unchanged.*

## 5. Step 3 — Patch Length Optimisation (HFSS Optimizer)

With the impedance matching fixed, the HFSS Quasi-Newton optimizer was used to tune the physical patch length (`pat_l`) to shift the resonance onto 866.5 MHz.

**Optimizer settings:**

| Setting | Value |
|---|---|
| Algorithm | Quasi-Newton (Gradient) |
| Free variable | pat_l only |
| Starting value | 82.3479 mm |
| Search range | 80–83 mm |
| Step size | 0.01–0.1 mm |
| Goal | dB(S(1,1)) ≤ −15 dB at 866.5 MHz |
| Max iterations | 1000 |

![Optimizer goals configuration]({{ '/assets/patch/step3_hfss/setup_goals.png' | relative_url }})

*Figure 10. HFSS optimizer goal: S₁₁ ≤ −15 dB at 866.5 MHz.*

![Optimizer variable configuration]({{ '/assets/patch/step3_hfss/setup_variables.png' | relative_url }})

*Figure 11. `pat_l` as the sole free variable, search range 80–83 mm.*

**Converged value: `pat_l` = 82.040 mm** (reduced by ~0.31 mm from the starting value).

## 6. Summary

| Parameter | Step 1 (Analytical) | Step 2 (Altium) | Step 3 (HFSS Opt.) |
|---|---|---|---|
| pat_l | 82.35 mm | 82.35 mm | 82.04 mm |
| cut_l | 30.57 mm | 20.59 mm | 20.59 mm |
| Resonance (S₁₁ min) | 859.9 MHz | 863.5 MHz | 866.1 MHz |
| S₁₁ at 865 MHz | — | −12.77 dB | −13.14 dB |
| S₁₁ at 866.5 MHz | −3.22 dB | −11.70 dB | −13.34 dB |
| S₁₁ at 868 MHz | — | −10.37 dB | −12.62 dB |
| Band < −10 dB | No | Yes (barely at 868) | Yes |
| Boresight gain | ~0.34 dBi | 0.927 dBi | 0.949 dBi |

The final design meets the −10 dB matching criterion across the full 865–868 MHz band. Boresight gain is ~0.95 dBi, which is typical for an FR-4 patch at this frequency due to dielectric losses.
